# Electric vehicle engineering data

This model represents a small electric-vehicle propulsion architecture, four stakeholder
requirements, their satisfying design elements, and verification cases.

- `vcrm_csv.roc` replaces a manually maintained verification cross-reference matrix.
- `bom_csv.roc` produces a design bill of materials from modelled parts and attributes.
- `engineering_dashboard.roc` creates a self-contained HTML engineering overview.
